类型系统、约束、模板与导入规则。

## 0. 基础设定

### 0.1 编码

本语言唯一合法的编码为 utf-8 NO BOM LF

### 0.2 文件类型

采用如下两种后缀名:

- `.infd` 允许模板定义和数据定义
- `.inft` 仅允许模板定义与导入语句（`!from` / `!env` / `!file` / `!var`）；
  不允许数据字段与结构级约束

### 0.3 顶层数据模型

顶层所有非模板定义共同构成一个 dict
